OCR DOCUMENT FLOW (LLM-BASED)

There is no model training. A multimodal LLM reads each page and extracts the fields defined for its
document type. Ground truth is used only to measure accuracy.

1. Upload documents.
   - Pages are rasterized to images and saved under datasets/raw-pages/<document_id>/.

2. OCR and classification.
   - Tesseract produces tokens and bounding boxes.
   - The document type is classified, which selects the field list in document_schemas.py.

3. LLM extraction.
   - backend/app/llm_extractor.py sends the page image and the numbered OCR tokens to Claude.
   - Claude returns each field with the OCR token indices it came from and a confidence.
   - Confidence >= 0.75 is pre-approved; the rest goes to human review.
   - Without ANTHROPIC_API_KEY (or if the call fails) the system falls back to OCR-only heuristics.

4. Human review.
   - Reviewers approve or correct fields in the dashboard. Corrections are kept for auditing.

5. Measure accuracy (optional, recommended).
   - Annotate a sample of pages in CVAT to create independent ground truth.
   - Run: dataset_tools predict, then dataset_tools evaluate.
   - Adjust the prompt or schemas, then run both again and compare.
   - Never use the model's own output as ground truth.

Simple order:
Raw documents -> page images -> OCR -> LLM extraction -> human review
Evaluation loop: annotate sample -> predict -> evaluate -> tweak prompt/schemas -> repeat
