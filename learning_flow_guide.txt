DOCUMENT FLOW (CLAUDE-ONLY)

There is no model training and no predefined field list. Claude reads each page image and decides what
the document is and which attributes it contains.

1. Upload documents.
   - Pages are rasterized to images and saved under datasets/raw-pages/<document_id>/.

2. Claude reads the pages.
   - backend/app/claude_extractor.py sends the page images (up to CLAUDE_PAGES_PER_REQUEST per request).
   - Claude returns the document type, a transcription of each page, the attributes it found with a
     confidence and page number, and any tables, as structured JSON.
   - Values that do not appear in their page's transcription are capped at confidence 0.5.
   - Confidence >= 0.75 is pre-approved; the rest goes to human review.
   - If Claude fails (bad key, rate limit, timeout, refusal, malformed response) the document is marked FAILED
     with a readable reason, and Retry runs it again. There is no OCR fallback.

3. Human review.
   - Reviewers approve or correct attributes in the dashboard. Corrections are kept for auditing.

Simple order:
Raw documents -> page images -> Claude (OCR + type + attributes) -> human review -> saved attributes
