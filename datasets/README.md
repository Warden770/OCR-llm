# Dataset Workspace

```text
datasets/
  raw-pages/                 PNG pages generated by the application, one folder per document id
  cvat/, ground-truth/, predictions/
                             left over from the removed token-level evaluation workflow; unused by the application
```

The application writes the rasterized page images to `raw-pages/<document_id>/page-###.png`, and the page
viewer serves them from there. Uploaded originals stay in `uploads/`.

The CVAT, ground-truth and prediction folders are not read or written by the application any more (the
token-level evaluation tools were removed with Tesseract). They can be deleted if you no longer need the files.
